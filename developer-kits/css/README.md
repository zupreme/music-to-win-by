# CSS Branch

Use this branch when you want a UI shell for the album player in a web app.

## File

- `background-music.css` - ambient layout and controls styling

## Suggested use

```html
<link rel="stylesheet" href="./background-music.css" />
```

Pair the CSS with the JavaScript branch for playback, or use it to skin your
own player controls around the album artwork and track status.
